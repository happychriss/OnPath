# OnPath

A simple, robust, fully offline hiking and biking app for Android.

- Komoot-like topographic map built from OpenStreetMap and Copernicus elevation data
- Smart offline routing on the phone (BRouter) for six profiles: bike touring, bike trekking, e-bike, MTB, MTB e-bike, hike (SAC T1–T5)
- Your position, route planning with via points, GPX import/export, track recording
- No account, no tracking, no server needed once a region is on the phone

Status: early prototype. First test region: Bozen / Meran / Algund (South Tyrol).
