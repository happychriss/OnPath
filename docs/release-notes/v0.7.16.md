# OnPath 0.7.16 – bikes respect one-way streets

- **Bike routes no longer go the wrong way up one-way streets** (touring, trekking, e-bike, MTB, e-MTB). Before, the
  wrong way on a small street cost only a little ("you may push your bike"); for mountain bikes that added up to
  1.9 km against one-ways in 56 test routes across Meran. Now it is used only as a last resort (23 m left – crossings
  and start/end points). Streets where bikes may ride both ways ("bikes excepted", contraflow lanes) still count as
  open.
- **The position dot has its small arrow again** (instead of the cone); it still turns with where you face.
- The ☰ menu no longer has "Check for updates" – Settings → Updates has it, and OnPath checks daily by itself.
