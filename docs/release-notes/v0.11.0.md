# OnPath 0.11.0 – better bike routes, clearer difficulty, sport type in GPX

**Bike routes**
- The bike profiles were tested on many routes and tuned.
- **Touring bike** is now a profile for a normal bike: bike paths and quiet ways, away
  from busy roads and rough gravel. **E-bike** routes the same way.
- **Trekking** keeps off busy roads on signed cycle routes and takes short ferries.
- Footways that are part of a signed cycle route are ridden. The amber "pushing" hint stays where you really have to
  push, including pedestrian zones.
- Bikes are never sent over a ferry that does not take bikes.
- **Saved Touring and E-bike plans get the new route line when you open them**, so the line can differ from before.
- Touring time is now for a normal bike: about 21–22 km/h on the flat at Average pace (was about 24).

**Difficulty**
- The label now counts trail technique too, for example "Moderate · T3".
- Hike bands are like Komoot's (Easy is up to about 2 h and 300 m up), so some hikes show a higher label than before.

**GPX**
- A GPX file from Komoot sets the activity on import. Your T level is kept when it fits; a grey line tells you when
  the activity was changed.
- GPX files exported from OnPath contain the activity too.
- An imported track without times shows the same time as the same line planned in OnPath.

**Fixes**
- "… m pushing" and steps hints, and times based on the surface, were missing on about one route in five.
- A point you put on a way is always visited – no more false "no way" message.
- Recorded hikes are saved with your T level (they were always saved as T3).
- A start or goal inside a building or on a tiny path with no way out (for example at Köln Dom) now works: the point
  moves to the nearest way you can use.
- Offline address search keeps answering while a map area's search data is updated.

**Map:** the bike markings on the map are rebuilt for the new profiles as your map areas refresh.
