# OnPath 0.11.8 – search, far points, export names

**Search**
- Opening the search again starts empty – the old text is gone; recent places stay.
- Big cities far away are found: "New York" no longer shows only shops of that name nearby.

**Far away points**
- A point that makes the plan very long (another continent) loads no maps until you answer the question: "Plan
  anyway" loads them, "Cancel" loads nothing.
- One route never loads more than 30 map regions at once – the rest follows on the tour.

**GPX export**
- File names say what they are: "Hilden - planned.gpx" and "Hilden - recorded.gpx" – a plan and its ride no longer
  overwrite each other.
