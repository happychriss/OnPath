# OnPath 0.7.15 – position dot like Google Maps, shared places in the right spot

- **The position dot shows where you face.** A soft blue cone at the dot turns when you turn (compass standing,
  walking direction moving) – like Google Maps. While navigating the map itself still turns by the route ahead, so
  the way stays straight up; turn by 90° and only the cone turns.
- **Fix: a place shared from Google Maps could land far away.** Google's short links often carry only name and
  address; OnPath then reads the Google page, which can contain other places' markers. That point is now checked
  against the address: more than 3 km apart → the address wins (tested with Gelateria Costantin, Meran).
- The orange ring shows only the place's name, not the whole address.
- Settings → Diagnostics notes where a shared place's position came from.
