# OnPath 0.13.5 – Save asks for the name, a simpler plan sheet

- **Save asks for the name again:** ☰ → Save route opens a small box with the name already selected – type a new one
  or keep it. Saving a saved route again updates it; a changed name renames it (still one route).
- **The plan sheet has no ⋯ menu any more.** Three small buttons with their names do the work: **Close plan**,
  **Reverse**, **Round trip**. Close plan asks first only when there are unsaved changes; a saved route stays in
  My routes.
- **Save route** is now the top item in ☰. A small green dot on ☰ shows that the plan has unsaved changes.
- **Save as copy**, **Export GPX** and **Share plan** are in My routes → ⋮ of the route.
- A tap on the route's time shows how it was calculated.
