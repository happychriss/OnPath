# OnPath 0.4.0

- **Updates directly on the phone:** Settings → Updates → "Check for updates"; a small notice on the home screen when a new version is out. Android asks you to confirm every install; tours and map data are kept.
- **Trail names on the map:** e.g. "Algunder Waalweg", Marlinger Waalweg, Tappeiner-Promenade, plus AVS trail numbers (25, 29A …).
- **Clearer map:** more contrast (greyer buildings, stronger paths), stronger railways and stations, new "High contrast" style (Settings → Map → Map style).
- **Import map data on the phone:** Settings → Map data → Import map data (.zip); download routing data directly.
- **Clear** asks first and removes the whole route.

Map data © OpenStreetMap contributors (ODbL).
