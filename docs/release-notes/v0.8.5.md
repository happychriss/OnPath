# OnPath 0.8.5 – app updates survive a weak connection

- **Updates resume:** when the connection breaks while an OnPath update downloads (it happened 4× on mobile data on
  21 Oct), the download continues where it stopped – up to 4 tries by itself, and the next tap on Update continues
  too instead of starting again.
- Hold on a route point: the same code as in 0.8.4, now covered by regression tests (core feature).
