# OnPath 0.6.4 – map import fix

- **New map data shows right after an import.** The map engine kept the old map file's index in memory, so an
  imported package could show gaps or old tiles until the app was restarted. After importing map files OnPath now
  restarts itself (during a tour it asks you to restart after the tour).
- **Mixed map files are named.** Map packages now carry a list of their files (`package.json`). If some files on the
  phone come from another package (an older import, a laptop copy), OnPath says which ones – in a message at start
  and in Settings → About, which also shows the package area and OSM date.
- **Paths zoomed out (zoom 11–12) are drawn again** – the layer had an invalid width rule and was skipped.

Import the South Tyrol package again (both zips from the downloads page) to get `package.json`.
