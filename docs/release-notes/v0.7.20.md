# OnPath 0.7.20 – route points can be held again

- **Fix: in Plan, route points could not be held (to delete or move them) since 0.7.19.** With "walking direction
  up" the map kept turning in Plan, so a point slid away under the finger. Now the map stops turning and following the
  moment your finger touches it; the compass brings walking direction back.
- **Fix: "walking direction up" switching itself back after a few seconds (Navigate).** Following now stops only
  when your finger actually touched the map in the last moment; any other stop is ignored (and noted in
  Settings → Diagnostics).
