# OnPath 0.8.1 – detailed maps load by themselves, clearly shown

- **Detailed maps download from the map server** (first GitHub release with map downloads: the release now carries
  the map server key). Set a point, open the app at a new place, or plan a long tour – OnPath fetches the map
  areas it needs.
- **Clear window while maps are built or loaded:** what is happening, why, progress per area, and only **Cancel**.
  Planning goes on with the overview map meanwhile.
- **Wi-Fi or mobile data?** Before larger downloads over mobile data, the window asks: *Wait for Wi-Fi* or
  *Use mobile data*.
- **Old map areas update themselves:** areas built before the small-streets map style are rebuilt and loaded again
  automatically – no need to delete anything.
- **Settings → Diagnostics → "Reset maps (like a fresh install)"** removes all downloaded map areas, so the app loads
  them again as on a new phone. Tours and settings stay.
- Fix: crash while the elevation profile was drawn very small (sheet animating).
