# OnPath 0.8.7 – holding a route point hits the right point

- **Hold on a route point:** a bigger catch zone (48 dp around the point). A hold a little further away (48–80 dp)
  asks "Point N" or "New point here" instead of guessing.
- **Delete in the point menu** always deletes the point you held – also when the plan changed while the menu was open.
- A late first GPS fix no longer closes a menu you have just opened (holding the map stops the start camera).
- **Diagnostics:** holds and point-menu actions (open, Delete, close) go into an event log in the diagnostics export.
- **Fresh install opens on the map** – no "map data missing" screen when map downloads are available, and no false
  "map file not found" problems.
- **Map:** private footways (e.g. a garden path) are no longer drawn green; country, capital and city names at low zoom.
- World overview map support. Release APKs will get it once the overview files are hosted (not yet).
- More core tests before every release (on the emulator): catch zone, Delete while a route is calculated, plan
  changed under an open menu, map reload under an open menu. The same tests now also run on a real phone.
