# OnPath 0.7.23 – the arrow shows where you face

- **The small blue arrow at your position shows where you point the phone** – turn around and the arrow turns,
  while the map keeps the way straight ahead (navigating with "walking direction up"). Standing it follows the
  compass, walking your walking direction. North up and when not following, MapLibre's own arrow shows it too.
- Built so that it can never disturb the map: the map is turned only by MapLibre (as in 0.7.22); the arrow is
  drawn on top of the dot.
