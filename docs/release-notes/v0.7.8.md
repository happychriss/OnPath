# OnPath 0.7.8 – a tour survives a restart

- **Keep recording after a restart or update.** At the first tour start OnPath asks once whether it may use location
  "Allow all the time". With it, a tour continues by itself when the phone restarts or OnPath is updated. OnPath uses
  it only while a tour is recording. Without it, a notification asks you to tap Continue, as in 0.7.7.
- Settings → Navigation shows which of the two applies, with a button to the app settings.
