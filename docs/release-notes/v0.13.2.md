# OnPath 0.13.2 – calmer messages, a clear start

- **Starting a tour far from the route.** If you start somewhere else, OnPath says "Route starts 31 km away" with
  *Guide me* or *Just record*, and the status card shows the same distance to the start. The route is no longer
  shortened to the end.
- **Clearer off-route question.** "You're 120 m off the route · new route 350 m longer". If a stop lies on the new
  way, you choose: via the stop, or skip it.
- **Stops on a path are always visited.** If the route still misses a stop, the stop stays where you put it and the
  plan says so. Nothing is moved quietly.
- **One calm message system.** White cards with a coloured edge, one at a time, always in the same place. No double
  question while the app is open.
- **Slider "Tour menu"** with the small line "Change route · Pause · End".
- **During a tour, saved routes can't be loaded.** A box says to end the tour first.
- **My routes** has two tabs, Planned and Done, and "New" / "Changed" tags for routes from the browser. "Save" is
  beside the plan's ⋯ while a route is unsaved.
- **Download chip** with a progress ring; its details open as a sheet.
- **Browser and phone plan the same way**, and the map looks the same per activity in both. Plans carry the routing
  version and the date of the routing data; the phone fetches newer routing data right away. A second browser can
  join a paired phone.
- **GPX export with named stops.** Importing the file again brings the stops back.
- **Round trips stay closed** when you delete a point from the map menu.
- **Recorded ascent and descent** are taken from the terrain under your track.
- **Map:** rock and scree symbols from zoom 14, stronger orchard and vineyard symbols.
