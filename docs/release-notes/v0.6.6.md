# OnPath 0.6.6 – high-contrast map fixed

- **High-contrast theme: paths, streams, lifts and service roads are back.** The theme writes peak names in
  "Noto Sans Medium", and that font was missing the "▲" sign in front of every peak. The map engine then dropped
  whole base-map tiles: unmarked paths (e.g. trail 32 below the Mutegg), streams, cable cars and access roads
  disappeared, only the green route bands stayed. Found with the new diagnostics export. A test now checks that every
  font has every sign the map uses.
- Diagnostics export: the live-map part (camera, layers, what is drawn on screen) works now.
