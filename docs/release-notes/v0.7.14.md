# OnPath 0.7.14 – your position indoors

- **Position via Wi-Fi when there is no GPS** (indoors, in a restaurant). When GPS has been silent for 30 s,
  OnPath shows the Wi-Fi position, if it is accurate to about 150 m – so planning ("Go here") works indoors. The GPS
  dot shows amber (weak) then. Rough cell-tower positions, which can be kilometres off in the mountains, are still
  never shown once GPS was seen. The recorded track stays GPS only.
