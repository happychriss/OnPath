# OnPath 0.6.7 – no silent errors

- **Every problem is recorded and shown.** Before, the app recovered from many errors quietly – that is how a missing
  font sign could break the high-contrast map for days unnoticed. Now every such place (about 120 in the app) reports
  to one problem log: what failed, what the app did instead, how often and when. This includes the map engine's own
  warnings and errors and crashes.
- **Settings → Diagnostics** lists the problems (newest first, with "× count" for repeats) and has *Clear problem
  list*. A new serious problem is announced once in the app ("Problem (map): … Details: Settings → Diagnostics"); if
  OnPath stopped unexpectedly, the next start says so.
- The diagnostics export contains the full problem list (`problems.json`).
