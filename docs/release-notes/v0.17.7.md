# OnPath 0.17.7 – a phone setup that never waits for the map

**First start**
- **The phone setup never waits for the map:** the map for where you are loads quietly in the background; no loading
  window opens over the setup any more.
- **The first map shows how far it is:** after the setup, while the map for here is still missing, a small card
  beside the activity button says "Karte wird geladen · 34 % · ca. 18 MB" – or offline "Noch keine Karte · Lädt,
  sobald du online bist". It goes by itself once the map is there.
- **Shorter, bigger setup texts:** the welcome and the setup steps say the same in about 40 % fewer words, one size
  bigger; at the largest font the pages scroll and the buttons stay reachable.
