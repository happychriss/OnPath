# OnPath 0.7.19 – one compass for Plan and Navigate

- **The compass choice is kept when you switch between Navigate and Plan.** One setting for both: with "walking
  direction up" the map keeps turning with you and follows you in Plan too (until you edit the plan or move the map);
  with "north up" it stays north up. Before, Plan always turned the map back to north.
