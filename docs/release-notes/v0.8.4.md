# OnPath 0.8.4 – holding a route point opens its menu again

- **Fix:** holding a route point added a new point instead of opening the point menu (Delete, Start here …).
  The point under the finger is now found from the plan itself, not from a copy kept with the map drawing that could
  lag behind (e.g. while the map reloads after a map update).
- Markers are redrawn when you come back from Navigate to Plan while the plan is followed.
- Diagnostics: a hold just outside a point is noted ("Press … dp from point N") – if it still happens, send the
  diagnostics export.
