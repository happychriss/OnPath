# OnPath 0.10.2 – the map for here only when it makes sense, map always up to date

**Map for where you are**
- **Opening the app no longer loads by itself without need.** When the map for here is ready on the server, it loads
  quietly in the background (seconds). When it must be prepared first (a few minutes), the blue bar asks:
  "Detailed map for here? · Not now · Load". No big loading window just for opening the app – handy in a car.
  Setting a point there loads it as always.

**Fixes from the field test of 0.10.1**
- **New map areas show at once** – before, they sometimes appeared only after restarting the app.
- **Places keep their spot while zooming:** each place has a fixed priority, so the same restaurant wins at every zoom
  (for map areas loaded or updated from now on); icons are placed before names – a name never pushes an icon away.
- **Background loading** is a small chip under ☰ ("⬇ Bad Waldsee · 34 %") instead of a full-width bar; questions and
  problems still show in the blue bar.
- A new plan in another place no longer carries the old route's name.
- Churches and chapels show by default.
