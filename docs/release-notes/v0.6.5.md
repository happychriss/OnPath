# OnPath 0.6.5 – diagnostics export

- **Settings → Diagnostics → Export diagnostics:** creates one file to send to the developer when the map or the app
  looks wrong – app version, map files (sizes, dates, PMTiles zoom levels and area), the map package check, which map
  style was loaded (and any style override in the data folder), what the map draws on screen right now (per layer),
  recording / navigation state and the app's own log (including the map engine's warnings). Leave the map at the
  problem spot, export, then share the file (mail, chat, Files). Nothing is sent by itself; the switch turns it off.
