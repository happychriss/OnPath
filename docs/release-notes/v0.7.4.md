# OnPath 0.7.4 – off-route vibration in the pocket

- **The off-route warning vibrates again with the phone in the pocket.** Android dropped the vibration while the app
  was not on screen (field test: the warning only blinked). It is now given as an alarm vibration, which comes
  through with the screen off.
- **New setting:** Settings → "Vibrate when off route" (on by default).
