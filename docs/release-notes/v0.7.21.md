# OnPath 0.7.21 – map turning back to the proven way

- **Fix: map turned slowly in jerky steps, and "walking direction up" switched itself off (0.7.15–0.7.20).** Since
  0.7.15 OnPath turned the map itself, frame by frame; that fought with MapLibre's own following, which then kept
  breaking off. The map is turned by MapLibre again (smoothly, as in 0.7.14), with all later improvements kept.
  The arrow at the dot shows the map's direction again (not where you face) – a separate "where I face" arrow comes
  back later, built in a way that cannot disturb the map.
- **Fix: holding a route point added a new point instead of opening its menu.** The point under your finger is now
  taken at the moment you touch the map, so it is found even if the map moved a little during the hold.
