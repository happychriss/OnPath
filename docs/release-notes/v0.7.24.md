# OnPath 0.7.24 – shared restaurants found by their address

- **Fix: places shared from Google Maps still landed far away.** Google sends name and address as one text
  ("PRIMUS Garden Bistrot, Via Goethe, 28, 39012 Merano BZ, Italien") and no coordinate. OnPath searched that whole
  text, which the address search does not know. Now name and address are taken apart and the address is searched
  first ("Via Goethe 28, 39012 Meran" – found exactly). Tested with PRIMUS Garden Bistrot and Gelateria Costantin.
