# OnPath 0.8.6 – delete points from a list

- **Route ⋯ → "Points… (delete)":** every route point (Start, stops, Destination, with its place name) with a Delete
  button. Works always – also when holding a point on the map does not open its menu. Undo brings a point back.
- **Diagnostics:** every hold on the map in Plan writes one line (which point was nearest, how far, whether the map
  was following or turned). If holding a point still adds a new point, send Settings → Diagnostics → Export.
- Before every release the core features now run on an Android emulator (hold → add point, hold a point → Delete,
  after a map reload, on a turned map, "Go here" with a moving GPS, back from Navigate to Plan, the point list).
