# OnPath 0.8.3 – plan on the latest map and routing data

- **After every route, OnPath checks the map along it.** If a newer map is ready, it loads in a few seconds (the map
  is softly veiled meanwhile) and switches. If the server has to build it first, a small hint says so – you keep
  planning on the current map. The big "Preparing map" window now only appears where there is no detailed map yet.
- **Nothing updates while the app is just open** – no more background map refreshes.
- **Mobile data by default** – no Wi-Fi / mobile question any more. Settings → "Maps only on Wi-Fi" if you prefer.
- **Newer routing data:** routing data older than 5 weeks is downloaded again after a route (about 200 MB, also on
  mobile data). The plan is then computed again; if the way changed you see "Route updated – newer way data".
- **During a tour the map never switches** to a newer version; that waits until you are back in Plan.

Map data © OpenStreetMap contributors (ODbL).
