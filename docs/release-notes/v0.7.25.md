# OnPath 0.7.25 – shared places faster

- **Shared places show up faster.** When Google's link already names the address, OnPath searches it straight away
  and no longer downloads the Google page first (one network request less, ~200 KB less). The page is only read when
  the address is not found.
- **"Finding the shared place…"** appears at once while the place is looked up, so you see that something happens.
