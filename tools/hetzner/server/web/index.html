Aufs Handy

Bei einer fertigen Karte auf Herunterladen tippen. Dann OnPath → Einstellungen → Kartendaten → Kartendaten importieren → die heruntergeladene Datei wählen. Die Routing-Daten lädt die App selbst (Einstellungen → Routing-Daten herunterladen), dabei auf die Gegend gezoomt sein.
